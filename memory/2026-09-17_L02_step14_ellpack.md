topics studied:
- ELLPACK/ITPACK stores sparse rows in rectangular arrays whose width is the maximum number of stored entries per row;
- values and their column indices are stored in aligned rectangular arrays;
- shorter rows require padding so every row has the same number of storage slots;
- regular row width gives predictable fixed-size loops and can be advantageous for parallel hardware such as GPUs;
- main tradeoff: if one or a few rows are much denser than the rest, the required width causes substantial wasted padding;
- ELLPACK is therefore most attractive when row nonzero counts are reasonably uniform;
- contrast with diagonal storage: diagonal formats exploit regularity in nonzero positions, whereas ELLPACK exploits regularity in row lengths.
