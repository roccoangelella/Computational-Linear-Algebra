topics studied:
- sparse matrix-vector product (SpMV) `y = A x` in CSR format;
- row `i` is traversed over positions `p = indptr[i], ..., indptr[i+1]-1`;
- each stored entry contributes `data[p] * x[indices[p]]` to `y_i`;
- `indices[p]` identifies the component of `x` associated with the stored matrix value `data[p]`;
- CSR SpMV visits only stored nonzeros and therefore has arithmetic work proportional to `O(nnz(A))` rather than scanning all `mn` matrix positions;
- explicit worked example with `A=[[10,0,0,-2],[0,3,0,0],[4,0,5,0]]`, CSR arrays `data=[10,-2,3,4,5]`, `indices=[0,3,1,0,2]`, `indptr=[0,2,3,5]`, and `x=[1,2,3,4]^T`, yielding `y=[2,6,19]^T`;
- importance of SpMV as a recurring computational kernel for later iterative/eigenvalue/Krylov methods.
