topics studied:
- MSR (Modified Sparse Row) and MSC (Modified Sparse Column) as formats for square sparse matrices that separate the main diagonal from off-diagonal entries;
- motivation for storing the diagonal separately: immediate access to `a_ii` while preserving compressed storage for the rest;
- conceptual MSR structure: diagonal array plus row-wise compressed off-diagonal entries;
- MSC as the column-oriented analogue;
- example matrix with diagonal `[10,20,30,40]` and row-wise off-diagonal entries;
- relevance to algorithms that repeatedly use diagonal entries, e.g. stationary iterative updates.
