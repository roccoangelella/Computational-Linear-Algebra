topics studied:
- scalar as a real coefficient multiplying a vector;
- linear combination `alpha_1 v_1 + ... + alpha_k v_k`;
- `span{v_1,...,v_k}` as the set of all possible linear combinations of the listed vectors;
- geometric meaning in `R^2`: one nonzero vector spans a line through the origin; two non-collinear vectors span the whole plane;
- matrix-vector multiplication `Ax` as a linear combination of the columns of `A`;
- equivalence between solving `Ax=b` and asking whether `b` belongs to the span of the columns of `A`;
- if `b` is not in that span, the system is inconsistent (has no exact solution).
