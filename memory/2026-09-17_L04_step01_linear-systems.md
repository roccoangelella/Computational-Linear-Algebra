topics studied:
- linear system written compactly as `Ax=b`;
- `A in R^{m x n}` as coefficient matrix, `x in R^n` as unknown vector, `b in R^m` as right-hand side;
- interpretation of matrix-vector multiplication as a set of `m` scalar linear equations in `n` unknowns;
- square systems (`m=n`) versus rectangular systems (`m!=n`);
- solution meaning: a vector `x` satisfying all equations simultaneously;
- geometric/column interpretation `Ax = x_1 a_1 + ... + x_n a_n`, so solving `Ax=b` asks whether `b` can be expressed as a linear combination of the columns of `A`;
- first statement of the square invertible case: unique solution for every `b` iff `A` is invertible; equivalent rank/determinant/kernel criteria will be developed in later steps.
