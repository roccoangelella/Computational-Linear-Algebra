topics studied:
- a norm as a function that assigns a nonnegative size to a vector and satisfies definiteness, absolute homogeneity, and the triangle inequality;
- vector 1-norm `||x||_1 = sum_i |x_i|`;
- Euclidean/2-norm `||x||_2 = sqrt(sum_i |x_i|^2)`;
- infinity norm `||x||_infinity = max_i |x_i|`;
- the same vector can have different numerical norm values because each norm measures size differently;
- matrix norms as measures of the size/amplification of a linear operator;
- induced matrix norm `||A|| = max_{x != 0} ||Ax||/||x||`;
- key consequence `||Ax|| <= ||A|| ||x||`;
- for induced norms, `||A||_1` is the maximum absolute column sum and `||A||_infinity` is the maximum absolute row sum;
- `||A||_2` equals the largest singular value, to be derived later in the SVD module;
- why norms are needed for error, residual, perturbation, convergence, conditioning, and approximation statements.
