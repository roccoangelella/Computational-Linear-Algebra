topics studied:
- a basis is a spanning set that is also linearly independent;
- a spanning but dependent set is not a basis because it contains redundant vectors;
- an independent set that does not span the whole target space is not a basis;
- bases are not unique, but every basis of the same finite-dimensional vector space has the same number of vectors;
- dimension is the number of vectors in any basis of the space;
- distinction between ambient dimension and subspace dimension, e.g. a line through the origin inside R^2 has dimension 1 while R^2 has dimension 2;
- a basis gives each vector a unique coordinate representation.
