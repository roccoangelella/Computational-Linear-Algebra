topics covered:
- motivation: approximate solutions of a large linear system `Ax=b` using a small number of directions;
- initial guess `x0` and correction `delta=x_m-x0`;
- search space `K`: admissible directions for correction (`x_m in x0 + K`);
- residual `r_m=b-Ax_m`, distinct from solution error;
- test/constraint space `L`: require `r_m` to be orthogonal to every vector in `L`;
- lecture's Galerkin choice `K=L` versus oblique choice `K != L`;
- 2-by-2 worked example using `K=L=span(b)`, solving for one scalar without assuming a zero residual;
- preview: Krylov methods make `K` from successive applications of `A` to the initial residual.
