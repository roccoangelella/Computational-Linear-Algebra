# Module 6 - Krylov subspaces, Arnoldi, FOM and GMRES

## 1. The large sparse system viewpoint

Consider a large linear system

`Ax=b`,

where explicitly factorizing `A` is expensive but multiplying a vector by `A` is feasible, especially when `A` is sparse. Krylov methods build approximations using only repeated matrix-vector products and orthogonalization.

The central subspace is

`K_m(A,b) = span{b, Ab, A^2 b, ..., A^{m-1} b}`.

It is called the **m-th Krylov subspace** generated by `A` and `b`.

Primary sources: `Slides/Lecture1030-Krylov.pdf`; transcripts `22Lecture1031_2.txt` through the Krylov part of `25Lecture1107.txt`; `PyLab03_krylov.ipynb` and solution; supplied deep reference `Saad_IteratveMethods_2000.pdf`.

## 2. Why Krylov spaces are computationally attractive

The basis vectors are not obtained by accessing every matrix entry or forming matrix powers explicitly. Starting with `b`, one repeatedly computes

`v, Av, A(Av), ...`.

For a sparse matrix, each multiplication can cost approximately `O(nnz(A))`. The hope is that a much smaller subspace `K_m`, with `m << n`, already contains a good approximation to the desired solution or eigenvector information.

Krylov spaces are nested:

`K_1 subseteq K_2 subseteq ...`.

Their dimension cannot exceed `n`. At some point the sequence stops growing in exact arithmetic.

## 3. Polynomial interpretation

Every vector in `K_m(A,b)` can be written

`p_{m-1}(A)b`

for a polynomial `p_{m-1}` of degree at most `m-1`. Therefore Krylov methods search for approximations produced by applying matrix polynomials to the initial data.

This connects convergence to how well polynomials can behave on the spectrum of `A`.

## 4. Minimal polynomial relative to a vector

The **minimal polynomial of `A` with respect to `b`** is the nonzero monic polynomial of smallest degree `d` such that

`p(A)b=0`.

If the degree is `d`, then

`b, Ab, ..., A^{d-1}b`

are linearly independent, while the next Krylov vector is a linear combination of the previous ones. Thus

`dim K_m(A,b) = min(m,d)`

until saturation.

In exact arithmetic, this finite-dimensional structure explains why a Krylov method can terminate with the exact solution after at most a finite number of steps under appropriate assumptions. Floating-point arithmetic complicates exact termination.

## 5. Why a raw power basis is undesirable

The vectors `b,Ab,A^2b,...` can become nearly linearly dependent and badly scaled. Working directly with this power basis is numerically unstable. Instead, Krylov methods construct an **orthonormal basis** of the same subspace.

That is the role of Arnoldi.

## 6. Arnoldi process

Start from a normalized vector

`q_1 = b/||b||_2`.

For `j=1,2,...,m`:

1. compute `v = A q_j`;
2. for `i=1,...,j`, compute
   `h_ij = q_i^T v` and update
   `v <- v - h_ij q_i`;
3. set `h_{j+1,j}=||v||_2`;
4. if `h_{j+1,j}` is nonzero, define
   `q_{j+1}=v/h_{j+1,j}`.

The vectors `q_1,...,q_m` form an orthonormal basis for `K_m(A,b)` in exact arithmetic. The coefficients form an upper Hessenberg matrix, meaning entries below the first subdiagonal are zero.

## 7. Arnoldi relation

Collect the basis vectors in

`Q_m=[q_1,...,q_m]`.

Arnoldi gives

`A Q_m = Q_{m+1} \bar H_m`,

where `\bar H_m` is `(m+1) x m` upper Hessenberg. Equivalently,

`A Q_m = Q_m H_m + h_{m+1,m} q_{m+1} e_m^T`.

The projected matrix is

`H_m = Q_m^T A Q_m`.

This is the small matrix representing the action of `A` on the Krylov subspace in the orthonormal basis.

## 8. Modified Arnoldi

Just as modified Gram-Schmidt rearranges orthogonalization for better numerical behavior, a modified Arnoldi implementation updates the candidate vector sequentially against each basis vector. The supplied lab asks for both basic and modified versions.

Loss of orthogonality is a practical issue. Reorthogonalization can be used when high orthogonality accuracy is required.

## 9. Breakdown

If

`h_{j+1,j}=0`

in exact arithmetic, then `Aq_j` already lies in the existing Krylov subspace. No new basis direction can be generated, so the subspace has become invariant under `A`. This is often a **happy breakdown** rather than a failure: the projected space can already contain the exact information needed.

Numerically, a tolerance is required to distinguish a true breakdown from a tiny nonzero value.

## 10. Projection idea for solving Ax=b

Choose an initial guess `x_0` with residual

`r_0=b-Ax_0`.

Seek an improved approximation in

`x_m = x_0 + K_m(A,r_0)`.

Using an orthonormal basis `Q_m`, write

`x_m = x_0 + Q_m y_m`.

The full `n`-dimensional problem is reduced to finding the small coefficient vector `y_m in R^m` using a condition imposed on the residual.

Different Krylov methods arise from different conditions.

## 11. FOM: Full Orthogonalization Method

FOM imposes the **Galerkin condition**

`r_m = b-Ax_m` is orthogonal to `K_m(A,r_0)`.

Thus

`Q_m^T r_m=0`.

For `x_0=0`, `r_0=b=beta q_1`, where `beta=||b||_2`. Using the Arnoldi relation gives the reduced system

`H_m y_m = beta e_1`.

Then

`x_m = Q_m y_m`.

So FOM solves a small `m x m` projected system rather than the original `n x n` system.

## 12. GMRES

GMRES - **Generalized Minimal Residual** - uses the same Krylov approximation space but chooses the coefficient vector that minimizes the residual norm:

`x_m = argmin_{x in x_0+K_m} ||b-Ax||_2`.

Using Arnoldi, this becomes the small least-squares problem

`min_y || beta e_1 - \bar H_m y ||_2`.

Thus the least-squares machinery from earlier modules becomes part of an iterative solver.

FOM enforces residual orthogonality to the search space; GMRES directly minimizes the residual 2-norm over the affine Krylov space.

## 13. Residual structures

For FOM, the residual is orthogonal to `K_m`. For GMRES, the minimization condition implies an orthogonality condition to `A K_m` in the standard Euclidean setting. This distinction is conceptually important: projection methods are characterized by a search space and a constraint/test space.

## 14. Exact arithmetic termination

If the minimal polynomial relevant to the initial residual has degree `d`, then the full Krylov space stops growing after `d` directions. Under nonsingularity and the usual conditions, an exact Krylov solution can be obtained in at most `d <= n` steps.

This statement does not mean that a practical method should run to `n`: the point of Krylov methods is that useful accuracy may be achieved with `m << n`.

## 15. Computational costs and memory

At iteration `m`, Arnoldi needs:

- one multiplication by `A`;
- orthogonalization against the existing basis;
- storage of the basis vectors;
- work on the small Hessenberg problem.

The matrix-vector product can be cheap for sparse `A`, but the basis storage and orthogonalization grow with `m`. Unrestarted GMRES therefore becomes more expensive over time. Restarted variants limit the basis dimension at the cost of potentially slower convergence.

## 16. Preconditioning concept

A preconditioner `M` is chosen so that solving systems with `M` is cheap while the transformed system is easier for an iterative method. For example,

`M^{-1}Ax=M^{-1}b`.

The goal is not merely to make entries smaller: it is to improve the spectral/geometric properties governing convergence. Preconditioning is a major part of the broader Krylov literature represented by the supplied Saad reference.

## 17. Connection to eigenvalue algorithms

Arnoldi is not only a linear-system tool. Because

`H_m=Q_m^T A Q_m`

is a small projection of `A`, eigenvalues of `H_m` - **Ritz values** - approximate eigenvalues of `A`. For symmetric matrices, Arnoldi simplifies to the three-term Lanczos recurrence studied later.
